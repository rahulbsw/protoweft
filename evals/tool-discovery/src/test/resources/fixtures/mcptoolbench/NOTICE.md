# Fixture provenance

The JSON files in this directory are small, hand-trimmed excerpts in the format of
[MCPToolBench++](https://github.com/mcp-tool-bench/MCPToolBenchPP) (commit
2bd35e58ed5ebe79bbb12df0f9919a34ed2cb037), MIT License, Copyright (c) 2026 mcp-tool-bench.
Tool descriptions and schemas are shortened; queries and labels are adapted for unit tests.
`pay/pay_single_demo.json` exists only to check that demo files are skipped.
